# NotebookLM Setup Guide

NotebookLM is optional for this course.

Use it if you want extra study support such as:

- your own notes on weak areas
- quick summaries of official materials
- flashcards or quizzes
- mind maps, infographics, or audio overviews

Do **not** treat NotebookLM as the source of truth. The official Anthropic
materials remain the authority for exam scope and correctness.

## Before You Start

You need:

- a Google account you can use for NotebookLM
- browser access to NotebookLM
- the CCA-F course files or official materials you want to load

Official NotebookLM help:

- [Create a notebook in NotebookLM](https://support.google.com/notebooklm/answer/16206563?hl=en)
- [Add or discover new sources for your notebook](https://support.google.com/notebooklm/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en-GB)
- [Frequently asked questions](https://support.google.com/notebooklm/answer/16269187?hl=en)

## Step 1: Open NotebookLM

1. Go to [NotebookLM](https://notebooklm.google.com/).
2. Sign in with your Google account.
3. If Google asks for age verification or account verification, complete that first.

If you use a work or school Google account and NotebookLM is unavailable, your
organization may control access. See:

- [Use NotebookLM with a work or school Google account](https://support.google.com/notebooklm/answer/16337734?hl=en)

## Step 2: Authenticate

NotebookLM authentication is just your normal Google sign-in.

Typical flow:

1. Enter your Google email.
2. Enter your password.
3. Complete 2-factor authentication if your account requires it.
4. Grant normal Google session access in the browser if prompted.

If you are already signed into Google in that browser, NotebookLM may open
directly without another prompt.

## Step 3: Create a Notebook for This Course

1. In NotebookLM, click **Create new notebook**.
2. Name it something obvious, such as:
   - `CCA-F Exam Prep`
   - `CCA-F Weak Areas`
   - `CCA-F Official Materials`
3. Keep one notebook for this course rather than mixing unrelated topics.

NotebookLM notebooks are isolated from each other, so keeping this course in its
own notebook makes review cleaner.

## Step 4: Add Sources

NotebookLM supports sources including:

- PDF
- Markdown or text
- Google Docs
- Google Slides
- web URLs
- pasted text
- YouTube URLs

Good sources for this course:

- Anthropic official CCA-F materials
- your own notes
- your weak-area summaries
- selected course docs from this repo if you want a companion notebook

Recommended first sources:

- `sources/anthropic/exam-overview.md`
- `sources/anthropic/exam-overview.md`
- `sources/anthropic/links.md`

Optional repo sources:

- `DOMAIN-MAP.md`
- `OFFICIAL-EXAM-ANCHORS.md`
- `SCENARIOS.md`
- `DISTRACTOR-PATTERNS.md`

To add them:

1. In your notebook, click **Upload a source** or **Add source**.
2. Choose whether to upload a file, add a Google Drive file, paste text, or add a URL.
3. Select the course files or official materials you want.
4. Wait for NotebookLM to finish importing them.

NotebookLM keeps a static copy of uploaded material at import time, so if you
change a source later, re-upload or refresh it there.

## Step 5: Good First Prompts

Once sources are loaded, use NotebookLM for support questions like:

```text
Summarize the five CCA-F domains in beginner language.
```

```text
Make me 10 flashcards on weak areas from these sources.
```

```text
What are the most common anti-patterns across these scenario materials?
```

```text
Give me a comparison table of the six official scenario families.
```

```text
Create a study guide for Domain 3 only.
```

## Step 6: How to Use It Alongside This Course

Best use:

- do the real course in Claude Code
- use NotebookLM as a sidecar study assistant
- use it to summarize, quiz, or visualize
- use Anthropic official docs plus this course materials as references

Do not use it to replace:

- official Anthropic source reading
- Claude Code session work
- this course's progression and gates

## Suggested Workflow

1. Run the course normally in Claude Code.
2. After a session, note weak areas.
3. Open NotebookLM.
4. Ask for:
   - flashcards
   - a short recap
   - a comparison table
   - a mind map or infographic if available
5. Bring the clarified understanding back into the next Claude Code session.

## Privacy and Caution

Before uploading anything:

- only upload material you are allowed to upload
- avoid sensitive private notes unless you are comfortable with that account context
- prefer official/public course materials for shared study notebooks

For personal Google accounts, Google's help indicates some interactions may be
reviewed to improve products or handle abuse/safety issues. Check Google's
current NotebookLM help and privacy documentation for the latest details.
