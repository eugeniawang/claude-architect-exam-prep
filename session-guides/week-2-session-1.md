## Scenario Anchor

A new teammate misses shared instructions because the wrong config layer was used.

## Teaching Flow

1. Explain user vs project vs directory scope.
2. Use this course folder as a concrete example.
3. Ask the learner where a few example instructions belong.
4. Run the lesson checkpoint.
5. Run `C3: Claude Code Team Setup` if needed.
6. End with the session quiz.

## Watch For

- learner confusing persistent instructions with settings
- learner missing why project scope matters for shared behavior

## Official Anchor

- scenario emphasis: choose the right Claude Code configuration layer for repeatable team behavior
- anti-pattern: putting shared project behavior in the wrong scope and creating drift or leakage
- code mechanic: compare project `CLAUDE.md`, subdirectory `CLAUDE.md`, and local settings by asking which layer should own an instruction
