# Week 1 Session 3 Guide

## Title

MCP and Tool Design Basics

## Official Mapping

- d2.1
- d2.2

## Scenario Anchor

A developer productivity agent keeps choosing the wrong tool because tool descriptions overlap.

## Teaching Flow

1. Explain MCP in beginner language.
2. Teach good tool descriptions and structured error categories.
3. Compare weak vs strong tool descriptions.
4. Run the lesson checkpoint.
5. Run `C2: Tool Description Rescue`.
6. End with the session quiz.

## Watch For

- learner treating MCP as “just plugins”
- learner missing retryable vs non-retryable errors

## Official Anchor

- anti-pattern: vague overlapping tool descriptions
- code mechanic: structured errors communicate category and retryability
