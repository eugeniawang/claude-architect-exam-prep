# Week 4 Session 1 Guide

## Title

Customer Support and Multi-Agent Research

## Official Mapping

- see `LESSONS.md`

## Scenario Anchor

Mix the customer-support and research-system scenarios in one session.

## Teaching Flow

1. Use scenario comparison, not abstract explanation.
2. Ask the learner to route work between coordinator, subagents, tools, and escalation.
3. Make them explain one tempting distractor per scenario.
4. Use `C7: Multi-Agent Research Routing` if needed.
5. End with a scenario-heavy quiz.

## Watch For

- learner assuming subagents inherit context
- learner over-distributing tools

## Official Anchor

- anti-pattern: sharing full coordinator context with every subagent
- code mechanic: explicit subtask context + scoped tool access

- if solid: `/start-w4-s2`
