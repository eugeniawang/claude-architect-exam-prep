# Week 2 Session 3 Guide

## Title

Plan Mode, Direct Execution, and Iteration

## Official Mapping

- d3.3
- d3.4
- d5.3

## Scenario Anchor

A repo-wide change request with unclear blast radius.

## Teaching Flow

1. Contrast small clear tasks vs broad uncertain tasks.
2. Teach plan mode, direct execution, and iterative refinement.
3. Ask the learner to classify example tasks.
4. Run the lesson checkpoint.
5. Run `C4: Plan or Execute`.
6. Assign `lab-3-plan-vs-execute.md` if needed.
7. End with the session quiz.

## Watch For

- learner overusing plan mode on tiny fixes
- learner skipping planning on architecture-scale changes

## Official Anchor

- anti-pattern: direct execution for large unclear changes
- code mechanic: `-p` and structured execution belong in CI-style automation contexts
