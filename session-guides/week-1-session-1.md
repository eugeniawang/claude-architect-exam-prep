## Title

What Claude Systems Are

## Official Mapping

## Scenario Anchor

Begin with a simplified support-agent example that separates:

- model
- tool
- agent
- workflow

## Teaching Flow

1. Frame the problem in beginner language.
2. Explain model vs tool vs agent with one concrete example.
3. Ask the learner to classify 3 examples.
4. Run the lesson checkpoint from `CHECKPOINTS.md`.
5. Run the Week 1 competency gate if the learner looks solid.
6. End with the session quiz.

## Watch For

- learner saying Claude, agent, and tool are interchangeable
- learner missing why context discipline matters

## Official Anchor

- scenario emphasis: classify model, tool, workflow, and agent responsibilities before judging architecture choices
- anti-pattern: treating every Claude-powered system as the same thing
- code mechanic: separate orchestration logic from tool capability so the learner can reason about what Claude does vs what external systems do
