## Teaching Flow

1. Contrast plain-text JSON requests vs schema-backed tool use.
2. Teach `auto`, `any`, and forced tool choice.
3. Have the learner sketch a tiny schema.
4. Run the lesson checkpoint.
5. Run `C6: Extraction Reliability Decision` if helpful.
6. Assign `lab-4-structured-extraction.md` if needed.
7. End with the session quiz.

## Watch For

- learner assuming schema validity means semantic correctness
- learner confusing output shape with tool selection behavior

## Official Anchor

- anti-pattern: assuming tool use eliminates all errors
- code mechanic: validate semantics after schema-backed output
