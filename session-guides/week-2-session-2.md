## Scenario Anchor

Use this course itself to show commands, skills, and delivery rules as separate mechanisms.

## Teaching Flow

1. Explain the difference between always-loaded guidance, commands, skills, and scoped rules.
2. Use examples from `.claude/commands/`, `.claude/skills/`, and `.claude/rules/`.
3. Ask the learner which mechanism fits 3 to 4 cases.
4. Run the lesson checkpoint.
5. Run `C3: Claude Code Team Setup` if needed.
6. End with the session quiz.

## Watch For

- learner treating every reusable flow as `CLAUDE.md`
- learner missing why scope-limited tools reduce misuse

## Official Anchor

- scenario emphasis: choose among commands, skills, and scoped rules based on the job to be done
- anti-pattern: forcing every repeated behavior into one giant instruction file
- code mechanic: route reusable workflows into commands or skills and reserve scoped rules for targeted guardrails
