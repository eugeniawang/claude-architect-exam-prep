# Week 3 Session 1 Guide

## Title

Explicit Criteria and Few-Shot Prompting

## Official Mapping

- d4.1
- d4.2

## Scenario Anchor

A CI review agent produces too many false positives because its prompt is vague.

## Teaching Flow

1. Show why vague instructions fail.
2. Rewrite one weak prompt using explicit criteria.
3. Add a small few-shot example.
4. Run the lesson checkpoint.
5. Run `C5: CI Review Prompt Upgrade`.
6. End with the session quiz.

## Watch For

- learner using “be conservative” style wording
- learner adding prose instead of specific criteria

## Official Anchor

- anti-pattern: vague prompt language
- code mechanic: explicit measurable review criteria
