How to get started (2 minutes)

No install, no accounts, no setup beyond Claude Code. The whole course lives in one folder.

  1. Step 1 — Download

    Download the repo as a ZIP and unzip it.

    Click Code > Download ZIP on the repo page and unzip it anywhere you like. Or git clone it. Either way you end up with one folder.

  2. Step 2 — Open in Claude Code

    Open that folder in Claude Code as a project.

    All the lessons, tracking files, and course materials are already inside it. Nothing else needed.

  3. Step 3 — Type Start

    Type Start and the course begins.

    The instructor runs a short onboarding, sets your pace (1, 2, or 3 months), and recommends your first session. Returning? Type continue.

  • Weak areas get flagged and sent back for another pass

  • Your progress file stays local in the folder

The seven principles the course is built around

  1. P1 — Use deterministic logic for correctness-critical work; use the model for judgment.
  2. P2 — Context is a finite, ordered, decaying working set, not memory.
  3. P3 — Match the mechanism to the problem's shape and cost.
  4. P4 — Make failure legible and propagate structured error context.
  5. P5 — Verify independently from generation; measure disaggregated.
  6. P6 — Decomposition needs complete coverage and managed seams.
  7. P7 — Preserve provenance and uncertainty; never silently collapse conflict.

These principles are an original framing built for this course, not official Anthropic material. They're a way to organize the exam domains so you understand the reasoning, not just the answers.

Phase 2: Tools, Code and Config

Domains 2 and 3

  1. Tool Design and Structured Errors
  2. MCP and Built-in Tools

Phase 3: Prompting, Reliability and Context

Domains 4 and 5

  1. Explicit Criteria and Few-Shot
  2. Structured Output and Validation-Retry
  3. Context Management and Reliability
  4. Escalation, Error Propagation and Provenance

Phase 4: Capstone

All domains
