The 7 Principles & Nemesis Map

Every exam anti-pattern is one principle, violated. Learn the seven; re-derive the rest.

The Prime Directive. The LLM is one probabilistic component in a system. Architecture is everything you wrap around it.
Right answers reach for the systems fix (control, context, verification, structure). Wrong answers “ask the model harder” (better prompt, more retries, self-confidence, sentiment) or over-build (a classifier, a fine-tune, a bigger model).

The seven root principles

P1Determinism for the correctness-critical; the model for judgment.Put code where being wrong is costly. Money/compliance/safety → a hook or gate, not a prompt.
P2Context is a finite, ordered, decaying working set — not memory.The model knows only what's in the window, where it sits, and in what form. Curate it.
P3Match the mechanism to the problem's shape and cost.Proportionate beats clever. Fix the root cause, not a symptom.
P4Make failure legible.Distinguish failure types; propagate structured error context so the system can recover.
P5Verification independent of generation; measurement disaggregated.The producer trusts itself. An average hides the failures that matter.
P6Decomposition needs complete coverage and managed seams.Specialise — but cover the whole problem and manage the handoffs (context, provenance).
P7Preserve provenance and uncertainty.Never silently collapse conflict or drop where a claim came from.

Exam tokens, by domain (recognise on sight)

D1 · Agentic (27%)

stop_reason (tool_use→continue, end_turn→stop, max_tokens) · Task + allowed_tools incl. "Task" · fork_session · --resume · PreToolUse/PostToolUse hooks

D2 · Tools & MCP (18%)

isError/errorCategory/isRetryable · tool_choice auto/any/forced · 4–5 tools (not 18) · .mcp.json vs ~/.claude.json · ${ENV_VAR} · Grep=content, Glob=names

D3 · Claude Code (20%)

CLAUDE.md hierarchy · @import · .claude/rules/ paths: · context: fork skills · plan vs direct · -p + --output-format json + --json-schema

D4 · Prompting (20%)

explicit criteria > “be conservative” · 2–4 few-shot + edge case · tool_use+schema (shape ≠ semantics) · retry-with-error (useless if data absent) · Batch API 50%/custom_id

D5 · Context & Reliability (15%)

lost-in-the-middle · case-facts block · /compact · escalate on policy gap / explicit request / no-progress (NOT sentiment) · access-failure ≠ empty result · claim→source provenance

The exam, in one move

Spot the option that “asks the model harder” or over-builds — eliminate it. The calm, deterministic, root-cause fix almost always wins.
