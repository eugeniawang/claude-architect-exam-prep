## Free Anthropic Courses (Official)

Anthropic publishes free, hands-on courses on GitHub — the best technical foundation for the CCA-F exam.

| Course | What it covers |
|---|---|
| [Anthropic Courses](https://github.com/anthropics/courses) | All official free courses in one place |
| [Prompt Engineering Interactive Tutorial](https://github.com/anthropics/courses/tree/master/prompt_engineering_interactive_tutorial) | Core prompting patterns with exercises |
| [Tool Use](https://github.com/anthropics/courses/tree/master/tool_use) | Function/tool calling, structured output |
| [Anthropic API Fundamentals](https://github.com/anthropics/courses/tree/master/anthropic_api_fundamentals) | API basics, messages, models |
| [Building Effective Agents](https://github.com/anthropics/courses/tree/master/building_effective_agents) | Multi-agent patterns, orchestration |
| [Real World Prompting](https://github.com/anthropics/courses/tree/master/real_world_prompting) | Production prompting techniques |

These align directly with CCA-F domains — tool use maps to D2, agents to D1, prompt engineering to D4.
