# Course Syllabus

Use these lesson entrypoints inside Claude Code.

## Setup and Navigation

- plain-language `start` · `continue` · `start next lesson` · `Let's do Session X`
- `/setup` — capture name, fun_facts, system, prep timeline, domain comfort
- `/start-course` — run Session 0 onboarding, then Session 1
- `/resume-course` — pick up from prior progress
- `/start-session <0-12>` — jump to any session directly
- `/help` — full command list + best next action
- `/course-menu` — same, in a menu format
- `/progress` — current session, readiness %, weak areas, next action
- `/reset-course-state` — clean cohort copy

## Practice & Readiness

- `/quiz-me` — exam-format checks from completed sessions only
- `/distractor-gauntlet` — rapid-fire spot-the-wrong-answer; streak counter; nemesis ID
- `/practice-exam` — mixed scenario set with repair plan (not a gate)
- `/mock-exam` — **final gate**: 4 of 6 official scenarios, random, 72% pass bar
- `/scenario-drill` — focused walkthrough of one official scenario
- `/principle-map` — ASCII + Mermaid map: meta-principle → 7 principles → nemeses → scenarios
- `/weak-areas` — targeted repair drill keyed to the violated principle
- `/daily-review` — due spaced-repetition reviews only
- `/recap` — key principle + nemeses + what's shaky from last session
- `/define X` — plain-language + exact exam token + which principle it serves
- `/reference` — source-anchored explanation from `SOURCE.md` / `COMPETENCY_MAP.md`
- `/grade-readiness` — readiness classification (Not Ready → Real-Exam Ready)
