# Skills Matrix

Use this file to judge whether the learner is exam-ready, not just familiar with terms.

## Mastery Levels

- `Level 1`: recognizes the term
- `Level 2`: explains the idea in plain English
- `Level 3`: chooses the right pattern in a small scenario
- `Level 4`: rejects tempting distractors and explains the tradeoff
- `Level 5`: transfers the pattern to a new scenario without prompting

## Skill Areas

### Agentic Loops
- Can explain `tool_use` vs `end_turn`
- Can name the safe loop control pattern
- Can reject natural-language loop termination

### Multi-Agent Orchestration
- Can explain coordinator vs subagent roles
- Can name what context must be passed explicitly
- Can explain why tool scope should stay narrow

### Tool Design and MCP
- Can improve a weak tool description
- Can classify structured error types
- Can explain project vs user MCP scope

### Claude Code Configuration
- Can place instructions at the correct hierarchy level
- Can distinguish skills, slash commands, and `CLAUDE.md`
- Can choose plan mode vs direct execution

### Prompt Engineering
- Can rewrite vague prompts into explicit criteria
- Can explain when few-shot examples help
- Can design a small extraction schema

### Reliability and Context
- Can explain when retry helps
- Can identify escalation triggers
- Can preserve provenance and key facts in a long workflow

## How To Use

After a session, rate each touched skill area from Level 1 to Level 5.

If any high-weight domain stays below Level 3 near the end of Week 3, assign targeted scenario drills before the mock exam.
