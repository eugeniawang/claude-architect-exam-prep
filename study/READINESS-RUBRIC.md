# Readiness Rubric

Use this to judge whether the learner is ready for the official practice exam and then the real exam.

## Not Ready

- weekly gates below 75%
- repeated confusion on high-weight domains
- can define terms but cannot apply them in scenarios
- relies on guessing instead of mechanism-based reasoning

## Emerging

- most session quizzes pass
- some weekly gates pass
- can solve guided scenarios but still misses distractor logic
- needs labs or weak-area repair for mechanics-heavy topics

## Practice-Exam Ready

- weekly gates consistently at or above 75%
- mock exam shows workable domain coverage
- can explain why wrong answers are wrong
- weak areas are specific, not broad

## Real-Exam Ready

- mock exam performance is stable
- weak areas have targeted repair plans
- learner can transfer concepts across mixed scenarios
- distractor elimination is fast and reasoned, not lucky

## High-Priority Readiness Signals

- Domain 1 and Domain 3 are not shaky
- learner can distinguish:
  - prompt vs hook/gate enforcement
  - tool use vs text parsing
  - project vs user scope
  - schema correctness vs semantic correctness
  - same-session review vs independent review
