# Lab 3: Plan Mode vs Direct Execution

## Official Mapping

- d3.3
- d3.4
- d5.3

## Scenario

Classify these tasks:

1. Add one null check.
2. Redesign a workflow across 40 files.
3. Add a CI review step using `-p` and structured output.
4. Investigate a vague bug with unclear blast radius.

## Learner Task

For each task:

- choose plan mode or direct execution
- give one-line reasoning
- name one distractor pattern a bad answer might use

## Pass Criteria

- plans for complex or uncertain tasks
- executes directly for small clear tasks
