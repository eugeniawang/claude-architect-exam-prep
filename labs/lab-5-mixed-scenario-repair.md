# Lab 5: Mixed Scenario Repair

## Official Mapping

- mixed-domain transfer

## Scenario

A learner keeps missing questions about:

- project vs user config
- prompt vs hook enforcement
- same-session self-review

## Learner Task

1. Group the misses into deeper misconception patterns.
2. Choose the best repair step:
   - scenario drill
   - practical lab
   - weekly gate retry
   - mock exam defer
3. Explain why one alternative is wrong or premature.

## Pass Criteria

- diagnoses weak areas precisely
- picks the right repair format
