# Reference

Progressive waterfall — read in this order, stop when you have the answer:

1. `course/GLOSSARY.md` — exact exam tokens and one-line definitions.
2. `course/COMPETENCY_MAP.md` — domain weights, principle linkage, nemesis roster.
3. `course/SOURCE.md` — **only if the learner explicitly asks for official verbatim domain/subdomain language or sample-question patterns.**

Return a concise, source-anchored explanation. Prefer COMPETENCY_MAP domain language plus a beginner translation. Always name which principle the concept serves.
