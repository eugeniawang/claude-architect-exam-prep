# Course Menu

Read:

- `study/SYLLABUS.md`
- `progress.json`

Show:

- The simplest path: `start`, `continue`, or `start next lesson`
- `/help` for the full command list
- Sessions done / remaining (13 total)
- Current recommended next action if progress exists

**Full command list:**

Setup & Nav: `/setup` · `/start-course` · `/resume-course` · `/start-session <0-12>` · `/help` · `/course-menu` · `/progress` · `/reset-course-state`

Learning: `/define X` · `/quiz-me` · `/distractor-gauntlet` · `/practice-exam` · `/mock-exam`

Drilling: `/principle-map` · `/scenario-drill` · `/weak-areas` · `/daily-review` · `/recap` · `/reference`

Admin: `/grade-readiness` · `/give-feedback` · `/notes` · `/reset-course-state`

Plain-language also works: `start` · `continue` · `Let's do Session X` · `Quiz me` · `Show me the principle map` · `Distractor gauntlet`

Mention `/reset-course-state` for a clean cohort copy.
